ADIF → Excel ✨

把 LoTW / QRZ / Club Log / N1MM / JTDX / TQSL 导出的日志，整理成一张干净的表格。 保留原始数据、自动识别字段、附上 DXCC 实体与 QSL 平信邮资。所有时间为 UTC。

⚠️ 先读这一段：网页版怎么运行

这个网页不能单独工作。它需要你电脑上运行一个本机小程序来读取 ADI 文件和生成 Excel — 因为浏览器无法直接写你磁盘上的文件，也不该把你的日志上传到任何服务器。

所以「网页版」= 你双击一个程序 → 它只监听 127.0.0.1（只有本机能访问）→ 浏览器打开这个界面 → 所有转换都在你自己电脑上完成，日志不出本机。

为什么不做成纯网页（比如 Pyodide 在浏览器里跑 Python）？那会让页面加载几百 MB， 而且需要把转换逻辑用 JavaScript 重写一遍 —— 两份实现必然会不一致。 本项目选择让三种界面共用同一份 Python 代码，代价是网页版要跑一个本机服务。

adif2xlsx-web.zip = 网页版　·　 adif2xlsx-ui.zip = 桌面窗口版　·　 adif2xlsx-cli.zip = 命令行版

🚀 网页版：三步开始

1
下载 adif2xlsx-web.zip，解压到任意文件夹（建议英文路径）。
2
双击文件夹里的 启动网页版.bat。会弹出一个黑色窗口 —— 转换期间请不要关掉它，浏览器会自动打开。
3
把 .adi / .adif 文件拖进页面，选好要输出的列，点「开始转换」。 Excel 会直接下载到浏览器的下载目录。

如果浏览器没自动打开，手动访问黑窗口里显示的地址（形如 http://127.0.0.1:8000/?token=…）。那串 token 是本次运行随机生成的， 用来确保只有你能访问。

🖥️ 不想跑服务？用桌面版

下载 adif2xlsx-ui.zip，解压后双击 adif2xlsx-ui.exe， 直接出来一个窗口，拖文件进去转换即可。功能和网页版完全一致 —— 同一份转换代码，同一套列选项。

需要批量处理或写脚本？用 adif2xlsx-cli.zip： 

adif2xlsx.exe log1.adi log2.adi -o 汇总.xlsx
adif2xlsx.exe 日志文件夹 -o 汇总.xlsx --columns required
adif2xlsx.exe --list-fields

📋 输出的两张表

工作表内容
QSOs 每条通联一行。第 1 行是英文列名（大写，公式和脚本用）， 第 2 行是中文标签（人看）。日期和时间是真正的 Excel 日期时间值， 不是文本。
Summary 波段 / 模式 / 呼号统计、总览、来源文件，以及逐列填充情况。 第 1 行就写明数据来源和「单元格为空」的含义。

必选列（永远输出）

CALL QSO_DATE TIME_ON_UTC TIME_OFF_UTC FREQ_MHZ BAND MODE SUBMODE RST_SENT RST_RCVD STATION_CALLSIGN SOURCE_FILE

所有时间都是 UTC，不做时区换算，并在列名里写明 _UTC。 你的日志里写的什么时间，导出的就是什么时间。

附加列：不硬编码字段名

除了上述必选列，工具会扫描 ADI 里实际出现的所有 ADIF 字段并各自成列。 某个字段如果在所有记录中都是空的，就不输出该列 —— 所以不同日志导出的列不完全一样， 这是刻意的。

可以按需筛选：「常用」「全部」「仅必选」，或者展开后逐列勾选。

🌍 DXCC 实体 ≠ 国家

「国家」和「DXCC 实体」不是一回事：中国 = 大陆 + 香港 + 澳门 + 台湾 + 黄岩岛； 俄罗斯 = 欧洲部分 / 亚洲部分 / 加里宁格勒；美国 = 本土 / 夏威夷 / 阿拉斯加 / 波多黎各。

本工具的 DXCC 表由 ARRL 官方 DXCC 列表生成 （2026 年 1 月版，340 个现有实体 + 62 个已删除实体）。 判定顺序是：日志自带的 DXCC 编号 → 日志自带的 COUNTRY → 呼号前缀。

这一点很重要：LoTW、Club Log、N1MM 都会写 DXCC 编号，而编号是权威的。 早期版本用了手写的编号表，导致 SP4DDS（波兰，269）被判成多哥 —— 国家错，邮资也错。现在表是生成的，并有 260 个区块的自动化审计。

✉️ QSL 邮资（中国邮政 平信）

按 20 克平信计，输出到 QSL_POSTAGE_AIR 列。 大陆地区显示单一数字 1.20；港澳台 航空 2.00 / 水陆路 1.50； 国际分区 1–4 档。不提供邮政服务的地区写「不通邮」。

资费会变。所以 Summary 表里同时写明资费标准的生效日期和核对日期， 以及来源 —— 一个过期的价格比没有价格更糟。挂号费等附加费用不计入。

🔒 隐私

  • 转换完全在本机完成，不上传任何数据，不联网。
  • 网页版服务只监听 127.0.0.1，其他机器访问不到。
  • 每次运行随机生成访问 token，防止本机其他程序误用。
  • 上传的临时文件在转换后立即删除，输出由浏览器下载。
  • 仓库里的测试日志是合成的假呼号，与真实通联记录零重叠（已用脚本核对）。
